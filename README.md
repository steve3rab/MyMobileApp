# MyMobileApp — version 11

## Nouveau portail
- écran d’accueil avec deux modules distincts ;
- **MyBudget** : budget, dépenses, statistiques, historique et réglages ;
- **MyAgenda** : horaires du lundi au vendredi pour Parent 1, Parent 2 et Enfant 1 ;
- bouton retour dans l’en-tête pour revenir au menu principal ;
- navigation inférieure affichée uniquement dans MyBudget ;
- données toujours stockées localement dans IndexedDB ;
- sauvegarde JSON complète et restauration validée avant remplacement ;
- purge de la base accessible depuis le portail d’accueil ;
- agenda plus lisible avec des champs horaires espacés ;
- navigation active synchronisée avec le défilement ;
- comparaison des dépenses avec le mois précédent ;
- brouillon temporaire de dépense et suivi du dernier export ;
- confirmations accessibles et contrastes renforcés ;
- cache PWA mis à jour en v11.
